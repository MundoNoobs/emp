Evaluación Sumativa 1 — Programación Front End TI3031 · Otoño 2026

Proyecto: Emprende Iquique — Vitrina de Emprendedores

INACAP Iquique

1. Herramienta Utilizada

Herramienta: Claude (Anthropic) — claude.ai
Versión / Modelo: Claude Sonnet (acceso web gratuito)
Período de uso: Durante el desarrollo del sitio web estático, sesión de trabajo única.

La herramienta fue utilizada como apoyo para la generación de estructura HTML inicial, sugerencias de CSS y revisión de criterios de accesibilidad. No se empleó para generar el contenido temático del sitio (textos, productos y nombres de emprendedores fueron definidos por el equipo).

2. Prompts Principales Empleados

# Prompt utilizado Propósito
1 "Crea una estructura HTML5 semántica para una vitrina digital de emprendedores locales de Iquique, con header, nav, main, secciones y footer." Obtener la estructura base del sitio con etiquetas semánticas.
2 "Aplica estilos CSS3 con variables de color, modo oscuro, grilla de productos con grid y tarjetas con hover. Usa paleta de colores verdes oliva." Generar el sistema de estilos visual del sitio.
3 "¿Qué atributos ARIA y criterios WCAG debo aplicar a un formulario de login con pestañas para que sea accesible?" Mejorar la accesibilidad del modal de inicio de sesión.
4 "Revisa este código HTML y dime qué le falta para cumplir con una rúbrica de evaluación que considera HTML5 semántico, CSS3, accesibilidad y buenas prácticas." Identificar mejoras necesarias antes de la entrega.
5 "Corrige el código pero mantén el diseño exactamente igual. Separa el CSS a un archivo externo, haz el h1 visible, crea páginas adicionales con navegación real y corrige los atributos alt de las imágenes." Aplicar correcciones de buenas prácticas al código existente.

3. Tipo de Apoyo Recibido

El uso de IA se centró en tres áreas principales:

Generación de estructura y código: La IA propuso una estructura HTML semántica inicial con las etiquetas correctas (`header`, `nav`, `main`, `section`, `article`, `footer`). El equipo revisó cada etiqueta y confirmó que correspondía al rol real de cada sección del sitio.

Sugerencias de estilo CSS3: La IA generó un sistema de variables CSS, clases para modo oscuro y un layout con Flexbox y Grid. El equipo ajustó la paleta de colores para que representara la identidad del norte de Chile (tonos verdes oliva y tierra).

Revisión de accesibilidad: Se consultó sobre criterios WCAG para formularios, contraste de colores, atributos ARIA y texto alternativo de imágenes. Las sugerencias fueron evaluadas y aplicadas selectivamente según su pertinencia para el sitio.

4. Ajustes y Modificaciones Realizadas

Las respuestas de la IA fueron revisadas críticamente y modificadas en los siguientes aspectos:

Temática cambiada a emprendedores locales de Iquique Paleta de color ajustada (verdes oliva en lugar de azul genérico) Nombres de negocios y productos definidos por el equipo Imágenes seleccionadas manualmente desde Unsplash Se agregó sección de preguntas frecuentes en contacto.html Se reescribieron los textos descriptivos del slider Se agregó aria-modal="true" que la IA no había incluido Se separó el JavaScript a main.js con manejo de errores Se añadió cierre de modal con tecla Escape Se corrigió el año del footer de 2024 a 2026

5. Declaración de Uso Responsable

Los integrantes de este equipo declaramos que la herramienta de inteligencia artificial fue utilizada únicamente como apoyo en el proceso de desarrollo, y que todas las sugerencias recibidas fueron revisadas, evaluadas y modificadas con criterio propio. El diseño conceptual del sitio, la elección de la temática, el contenido textual y la toma de decisiones estructurales fueron realizados por el equipo.
